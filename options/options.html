🤖 AI 服务

OpenAI 兼容端点，如 https://api.deepseek.com（会自动拼接 /chat/completions）
存储于 chrome.storage.local，仅在扩展后台发送请求时使用
DeepSeek 现行模型：deepseek-v4-flash / deepseek-v4-pro。旧的 deepseek-chat、deepseek-reasoner 已下线，保存时会自动改写为 deepseek-v4-flash。
与 agent 一致的六档分级：关闭 / low / medium / high / xhigh / max。开启后模型先输出思考过程（reasoning_content），侧边栏以灰框展示，再给正式回答。
DeepSeek 的实际映射：low→low，medium/high/xhigh→high，max→max；即在 DeepSeek 上真正有区别的是 low / high / max 三档。
⚠️ 思考模式下 temperature 无效（官方文档明示），因此开启思考时不会发送该参数。
⚠️ 隐私提示：使用第三方兼容 API 时，字幕与提问内容会发送到该服务商（如 Base URL 对应的域名）。扩展本身不收集任何数据。

🖼️ 视觉模型（截图总结画面识别）

用于识别课程截图中的数学公式/板书，OpenAI 兼容 vision 接口。不配置时「📸 截图总结」无法使用。截图本身不需要额外权限（直接读取播放器视频帧）。
如通义 qwen-vl（上例）、智谱 GLM-4V：https://open.bigmodel.cn/api/paas/v4、本地 Ollama：http://127.0.0.1:11434/v1；也可用 DeepSeek 实验性视觉模型：Base URL 填 https://api.deepseek.com，模型填 deepseek-v4-flash-vision-exp
